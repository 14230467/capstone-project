# Infrastructure Changes with Branching Policy

Manage infrastructure changes using git branching and Pull Request Reviews

## Implementation
- Created a feature branch
- Made changes in the feature branch
- Committed and pushed changes
- Created a pull request for review
- Merged the changes into the main branch after review

## Branching Strategy
- main: Stable branch
- feature/project11: Branch used for project changes

## Outcome
Successfully demonstrated a feature branch workflow and Pull request-based change management
